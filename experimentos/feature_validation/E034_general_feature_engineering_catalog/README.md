# E034 — General Feature Engineering catalog

Convierte la evidencia de E031-E033 en una taxonomía gobernada:

- tested model candidates;
- next challengers;
- routing-only;
- policy guardrails;
- blocked/rejected;
- data gaps.

El objetivo es que ABT v2 no sea una acumulación de columnas: cada feature debe declarar stage, semántica point-in-time, riesgo de drift y evidencia de promoción.
