# LLM / AI

AI use is mandatory in the original assessment and is now explicitly documented in `AI_USAGE.md`.

Current policy:
- LLM is used as a methodology/analysis copilot;
- deterministic structured signals are preferred over paid/nondeterministic extraction;
- E017/E018 are negative evidence for listing semantic features;
- no `llm_*` variable is a LeadQuality feature;
- a new LLM feature hypothesis requires materially new unstructured information and a pre-registered residual-value test.
