# Metrics

Population authority is explicit:

- DEVELOPMENT fold/macro metrics: model/ablation selection evidence;
- CALIBRATION metrics: calibrator selection evidence;
- June procedural-holdout metrics: **DIAGNOSTIC_ONLY_NON_PRISTINE**.

For the constant Base Rate champion, PR-AUC (trapezoidal), Lift@k, Precision@k, Recall@k and calibration slope are undefined because no ranking/score variation exists. See `../METRIC_DEFINITIONS.md`.
