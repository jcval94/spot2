# ABT artifacts

This directory contains reproducibility evidence for the definitive point-in-time ABTs.

## Committed in full

- `score_spine.csv`: 27,576 scoring snapshots.
- `lead_quality_audit_all_snapshots/`: all 27,576 T0/T1/T2 snapshots, sharded CSV.
- `lead_quality_model_ready/`: 19,298 valid-label rows, sharded CSV.

## Large row-level objects

The full Candidate Spot and Inventory Serviceability tables each contain **1,114,990 rows**. They are deterministic derived data, so the repository does not version their full CSV representation.

Instead it commits:

- complete per-`prediction_key` summaries for all 27,576 decisions;
- deterministic 5,000-row row-level samples;
- full logical row counts and fingerprints;
- builders that materialize the complete tables as Parquet from raw.

Runtime full outputs:

- `candidate_spots.parquet`
- `inventory_serviceability_state.parquet`

They are generated by `build_candidate_spots.py` and `build_inventory_state.py`.

## Why

This keeps the clean-room repository auditable without adding hundreds of MB of reproducible derived data. The source of truth remains raw Parquet + committed code/contracts.

See `qa_summary.json` and `artifact_manifest.json`.
