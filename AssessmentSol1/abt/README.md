# ABT

No ABT is constructed in PROMPT 0.

The future canonical grain is expected to be a scoring decision, not a static lead row:

`lead_id × stage × score_time × current-inquiry-or-T0`.

That expectation is evidence-informed by E016/E030 but must be reimplemented from raw candidate tables inside this directory. Historical E030 CSVs/ABTs are explicitly forbidden as inputs.
