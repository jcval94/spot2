# Inventory outputs

These are frozen DEVELOPMENT-only policy-selection artifacts. They contain no target, Lead Quality prediction, CALIBRATION selection result or June procedural-holdout result.

`development_policy_evaluation.json` is the audit manifest. CSV files expose freshness sensitivity, ranking comparison, area-fit comparison and cohort stability.

The exact Polars Inventory builder could not be executed in the current tool runtime because Polars is unavailable; the policy metrics were independently recomputed directly from raw repository blobs. The committed test suite is the reproducible exact-path gate.
