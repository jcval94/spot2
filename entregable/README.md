# Entregable final — Spot2

Esta carpeta concentra la versión final en español de los entregables del assessment.

## Principio de autoridad

La solución base y autoridad principal es **Codexway**.

La evidencia de **AssessmentSol1** y **experimentos/** se utiliza únicamente para:

- enriquecer la narrativa con hallazgos adicionales;
- demostrar robustez o reproducibilidad independiente;
- documentar pruebas negativas y decisiones descartadas;
- explicar riesgos de leakage, temporalidad y calidad de datos;
- proponer hipótesis que ya fueron contrastadas experimentalmente.

Cuando dos líneas de trabajo usan distinto target, población, grano, ventana temporal o arquitectura, sus métricas **no se combinan ni se presentan como si fueran directamente comparables**. Codexway conserva la autoridad de decisión y las demás fuentes se etiquetan como evidencia complementaria.
